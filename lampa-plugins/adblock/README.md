# Lampa AdBlock

Локальный плагин для Lampa, отключающий два штатных рекламных механизма:

- preroll при запуске видео и между эпизодами;
- overlay-баннер Google IMA в плеере.

Плагин перехватывает только запросы Lampa `/api/ad/get/preroll` и
`/api/ad/get/banner`, а также удаляет VAST-поля, переданные плееру сторонними
плагинами. Остальные запросы и работа плеера не изменяются.

## Установка

Добавьте в Lampa через **Настройки -> Расширения -> Добавить плагин**:

```text
https://cdn.jsdelivr.net/gh/darkworon/openwrt-mt6000@main/lampa-plugins/adblock/plugin.js
```

После первой установки перезапустите Lampa. Переключатель находится в разделе
**Настройки -> Ещё -> Блокировать рекламу**; при его изменении Lampa
перезапустится автоматически.

## Диагностика

В консоли браузера доступен объект `window.LampaAdBlock` со счётчиками
заблокированных запросов, очищенных VAST-параметров и удалённых элементов.
