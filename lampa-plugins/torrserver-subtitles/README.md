# TorrServer Subtitles for Lampa

Плагин приводит встроенные субтитры при воспроизведении из TorrServer
к штатному оформлению Lampa в браузере и на LG webOS.

## Что исправляет

`online_mod.js` передаёт внешние субтитры через поле `subtitles`, поэтому Lampa
рисует их собственным слоем. Встроенные дорожки прямого torrent-потока попадают
в нативный `TextTrack` браузера и обходят настройки Lampa.

Плагин включается только для torrent-воспроизведения:

- сохраняет штатный выбор встроенной дорожки;
- скрывает нативный browser-cue;
- выводит текст через штатное событие `subtitle` Lampa;
- применяет размер, тёмный фон, обводку и сдвиг времени из настроек плеера;
- на webOS синхронизирует размер и фон через `com.webos.media`, поскольку
  системные embedded-субтитры не являются DOM-элементом;
- не изменяет `online_mod.js` и другие онлайн-источники.

Для графических дорожек (например, PGS) телевизор уже получает готовые
изображения. Их шрифт и фон изменить невозможно; настройка применяется к
текстовым embedded-дорожкам, если прошивка телевизора поддерживает эти методы.

## Установка

Добавьте в Lampa через **Настройки -> Расширения -> Добавить плагин**:

```text
https://darkworon.github.io/l.js
```

Итоговый bundle также содержит блокировку рекламы. После установки
перезапустите Lampa. Переключатель находится в разделе
**Настройки -> Ещё -> Оформлять torrent-субтитры как в Lampa**.

Для диагностики в консоли доступен объект
`window.LampaTorrserverSubtitles`.
