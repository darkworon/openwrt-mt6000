# TorrServer Embedded Subtitles for Lampa

Плагин извлекает встроенные текстовые субтитры из прямого потока TorrServer и
рисует их DOM-слоем Lampa. Поэтому размер, обводка, тёмный фон, отступы и
поведение при открытой панели совпадают с субтитрами, которые Lampa получает от
`online_mod.js` отдельным SRT/VTT-файлом.

## Как работает

- включается только для воспроизведения через текущий TorrServer;
- читает заголовок и нужные участки MKV/MP4 запросами HTTP Range, не загружая
  весь файл;
- поддерживает текстовые SRT, ASS/SSA и MP4 `mov_text` дорожки;
- выключает нативную embedded-дорожку после обнаружения поддерживаемого текста,
  чтобы системные и DOM-субтитры не отображались одновременно;
- использует штатные классы `.player-video__subtitles` и настройки субтитров
  Lampa;
- показывает дорожки в формате `номер / язык / название`, используя метаданные
  MKV, `ffprobe` и webOS вместо имени кодека вроде `utf8`;
- игнорирует встроенные в ASS шрифт, размер и цвет, чтобы оформление задавала
  Lampa, но сохраняет переносы, жирный, курсив, подчёркивание и позиционирование;
- предпочитает английскую дорожку, когда включён плагин English Tracks, и
  сохраняет ручной выбор для конкретного потока;
- возвращает фокус на кнопку субтитров после закрытия списка, не ломая переход
  к таймлайну и перемотку;
- не вмешивается в `online_mod.js` и другие онлайн-источники.

Цвет, контур и вертикальная позиция доступны прямо во время просмотра через
**шестерёнка -> Субтитры · TorrServer** и глобально через **Настройки -> Плеер ->
Субтитры TorrServer**. Режим цвета `Авто` оставляет штатный белый на SDR и
использует мягкий белый на HDR10, HLG и Dolby Vision. HDR определяется по
`ffprobe`, метаданным воспроизведения и имени файла в TorrServer URL. Контур
TorrServer можно отключить независимо от глобальной обводки Lampa.

Графические PGS/VOBSUB дорожки не поддерживаются: их нельзя превратить в
стилизованный текст без отдельного OCR-конвейера. Сервер должен поддерживать
HTTP Range; TorrServer его поддерживает.

## Установка

Добавьте в Lampa через **Настройки -> Расширения -> Добавить плагин**:

```text
https://darkworon.github.io/l.js
```

После обновления полностью перезапустите Lampa. Для диагностики в консоли
доступен объект `window.LampaTorrserverSubtitles`.
