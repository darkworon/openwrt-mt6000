# Lampa English Tracks

Плагин выбирает английскую аудиодорожку и английские полные субтитры при
каждом запуске встроенного плеера Lampa.

Поддерживаются языковые метки `en`, `eng`, `English`, `Английский`, а также
названия дорожек из `translate.tracks`, которые передают `online_mod.js` и
TorrServer/ffprobe. Если фильм изначально англоязычный, дорожка с названием
`Original` также считается английской.

Ручной выбор запоминается отдельно для карточки фильма или сериала. Для новых
карточек снова применяется английский язык. Отключение субтитров через меню
плеера тоже сохраняется.

## Установка

Добавьте в Lampa через **Настройки -> Расширения -> Добавить плагин**:

```text
https://cdn.jsdelivr.net/gh/darkworon/openwrt-mt6000@main/lampa-plugins/english-tracks/plugin.js
```

После первой установки перезапустите Lampa. Настройки плагина находятся в
разделе **Настройки -> Ещё -> English Tracks**.

## Ограничения

Плагин управляет дорожками встроенного плеера Lampa. Системные внешние плееры
вроде VLC, Infuse или Android-плеера выбирают дорожки самостоятельно.

Если английской дорожки или английских субтитров в потоке нет, плагин оставляет
выбор Lampa без изменений.

## Диагностика

В консоли браузера доступен объект `window.LampaEnglishTracks` со счётчиками
выбранных и восстановленных дорожек и методом `preferences()`.
